# Contribuir

Abra issue descrevendo o problema sem dados privados. Para contribuir: fork, branch, alteração focada, testes e pull request. Não inclua .env, data, credenciais, cópia de ativos de clientes ou exports de workflows com dados fixados.

Antes de enviar: execute os testes Python, testes JavaScript e scripts/check_public_source.py descritos no README. Preserve aprovação humana, vínculo entre aprovação e versão, deduplicação, consentimento e separação de contas. Toda nova integração precisa de guia de configuração, escopos, revogação e limites reais.

Correções de segurança devem seguir SECURITY.md. Sugestões e alterações são recebidas sob a licença MIT do projeto; dependências e materiais externos precisam de atribuição/licença compatível.
